# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussion about the work. Harassment, personal attacks and discriminatory language are not tolerated in issues, pull requests or any other project space.

## Reporting

Report unacceptable behaviour privately to the maintainer, [@MdTanvirHossainTusher](https://github.com/MdTanvirHossainTusher). Reports are handled confidentially. The maintainer may edit or remove comments and contributions, or block contributors, who break this code.
